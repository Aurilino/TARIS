# Эталон без противника

`adversary_base_before.json` — точная копия `runs/adversary/base_before.json`, снятого 03.11.2026 до подключения `adversary` к миру. Команда создания: `python scripts/check_adversary.py --save-base runs/adversary/base_before.json`.

Восемь конфигураций S0/S2/S6/S8, matched/mismatched, seed 19; параметры — функция `small` в скрипте проверки. Записаны хэши таблиц и значение калибровки, без сериализации конфигурации и меток времени. Среда снятия: Windows / Python 3.12, pandas 3.0.6, numpy 2.5.4. При изменении версий численных библиотек расхождения требуют разбирательства, а не автоматической перезаписи эталона.

Файл эталона не содержит ключей или открытых пользовательских данных. Его нельзя переснимать после изменения генератора и затем выдавать совпадение за регрессию относительно прежней версии.

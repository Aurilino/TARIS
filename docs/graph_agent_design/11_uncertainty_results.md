# Р3.2. Проверка по нескольким моделям риска

Дата: 10 ноября 2026 года. Реализовано в автономном прототипе; основной симулятор не изменён.

## Постановка

Размещение принимается, только если требования выполняются для каждой модели конечного ансамбля:

$$
A^{+}(S)=\max_{m\in\mathcal{M}}A_m(S),\qquad P_L^{+}(S)=\max_{m\in\mathcal{M}}P_{L,m}(S).
$$

где:
- \(S\) — размещение объекта;
- \(\mathcal{M}\) — конечный набор моделей;
- \(m\) — модель из набора;
- \(A_m(S)\) — недоступность объекта в модели;
- \(P_{L,m}(S)\) — вероятность потери объекта в модели;
- \(A^{+}(S),P_L^{+}(S)\) — максимальные риски по моделям.

Ограничения применяются к максимумам. Каждый объект проверяется по полным совместным моделям. Максимумы отдельных рёбер служат критерием поиска, но сами по себе не образуют новое совместное распределение.

## Ансамбли

- `point`: одна обученная модель.
- `bootstrap`: точечная модель и восемь моделей по повторным выборкам временных блоков длины восемь окон.
- `structural`: точечная модель, базовая модель и стресс базовых индивидуальных и групповых вероятностей с множителем два.
- `combined`: все перечисленные модели.

Блок пересэмплируется целиком с сохранением масок наблюдений, контекстов и связи между слоями. Время получения сообщения не изменяется, будущие сообщения исключаются. Кратности выборки задаются отдельно, исходный журнал не дублируется. Сила сглаживания выбирается на прошлом, как в Р3.

Множитель два и длина блока заданы до новых прогонов, не подобраны по их истине. Это исследовательские настройки, не откалиброванные параметры реальной сети. Восемь повторных выборок слишком мало для заявления хвостового статистического уровня. Структурный стресс — явно заданное предположение, не доверительная граница.

## Результаты на новых зёрнах 6–11

Те же требования: два чанка для сборки, недоступность не выше 0,08, вероятность потери за учебное окно не выше 0,025.

| Проверка | Решение найдено | Среднее число чанков | Нарушения истинного лимита доступности | Нарушения лимита потери |
|---|---:|---:|---:|---:|
| Точечная | 6/6 | 3,33 | 2/6 | 0/6 |
| Повторные выборки | 6/6 | 3,83 | 0/6 | 0/6 |
| Структурный стресс | 6/6 | 6,00 | 0/6 | 0/6 |
| Объединённая | 6/6 | 6,00 | 0/6 | 0/6 |

Средний истинный риск недоступности выбранного размещения: около 0,0690 для точечной проверки, 0,0407 для повторных выборок, 0,0090 для стресса. Риск оценивается внешним оценщиком, не передаётся агенту.

Повторные выборки в этом опыте добавили в среднем половину чанка на объект. Структурный стресс потребовал все ноды и оказался существенно дороже. Нулевое число нарушений в шести мирах не доказывает гарантию на произвольной среде.

Графовый поиск и полный перебор сравниваются для каждого ансамбля. Изменение ансамбля меняет и допустимость, и консервативный графовый критерий; сравнение минимального числа чанков выполняется точным эталоном. Эвристический поиск всё ещё не доказывает оптимальность.

## Файлы и проверки

`prototype/uncertainty.py`, `run_uncertainty.py`, `test_uncertainty.py`, `uncertainty_results.json`.

Всего успешно выполнено 35 проверок: 28 прежних и семь новых. Проверены совпадение с исходной моделью при одном участнике, монотонность риска при добавлении модели, отличие объектной проверки от реконструкции по максимумам рёбер, воспроизводимость блоков, исключение будущих аудитов, веса окон, новые ноды и неверные настройки.

Далее — Р4: модель исполнения восстановления. Доверительный уровень для реальной сети пока не заявляется; возможное неверное описание риска общим для всех участников ансамбля остаётся открытой проблемой.

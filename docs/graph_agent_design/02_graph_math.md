# Шаг 2. Полный граф доступности

Статус: согласовано в обсуждении. Записано 7 ноября 2026 года.

Этот граф описывает временную недоступность. Граф безвозвратной потери чанков предстоит определить отдельно. Формулы задают модель, но не реализованный алгоритм оценивания.

## Граф

$$
G(t,H) = \bigl(V(t),E(t),W(t,H)\bigr).
$$

где:
- \(t\) — момент принятия решения;
- \(H>0\) — горизонт оценки;
- \(V(t)\) — множество рассматриваемых нод;
- \(E(t)\) — все неупорядоченные пары разных нод;
- \(W(t,H)\) — набор весов рёбер;
- \(G(t,H)\) — полный взвешенный граф.

## Недоступность ноды

$$
D_i(s) =
\begin{cases}
1, & \text{нода } i \text{ недоступна в момент } s,\\
0, & \text{нода } i \text{ доступна в момент } s.
\end{cases}
$$

где:
- \(i\) — индекс ноды;
- \(s\) — момент времени;
- \(D_i(s)\) — индикатор недоступности.

## Вес ребра

$$
w_{ij}(t,H) = \frac{1}{H}\int_t^{t+H}
\widehat{\mathbb{P}}\!\left(D_i(s)=1,\ D_j(s)=1\mid\mathcal{F}_t\right)\,ds,
\qquad i\ne j.
$$

где:
- \(w_{ij}(t,H)\) — ожидаемая доля времени совместной недоступности нод;
- \(i,j\) — индексы разных нод;
- \(t,H,s\) — момент решения, горизонт и момент внутри горизонта;
- \(D_i(s),D_j(s)\) — индикаторы недоступности;
- \(\mathcal{F}_t\) — наблюдения сети, доступные агенту к моменту решения;
- \(\widehat{\mathbb{P}}\) — вероятность, оценённая агентом.

Вес включает регулярные расписания и случайные совместные отключения. Это совместный риск, а не корреляция и не превышение над независимостью. Вес не обязан удовлетворять неравенству треугольника; геометрическая картинка не заменяет матрицу весов.

## Собственный риск

$$
q_i(t,H) = \frac{1}{H}\int_t^{t+H}
\widehat{\mathbb{P}}\!\left(D_i(s)=1\mid\mathcal{F}_t\right)\,ds.
$$

где:
- \(q_i(t,H)\) — ожидаемая доля времени недоступности ноды;
- \(i\) — индекс ноды;
- \(t,H,s\) — момент решения, горизонт и момент внутри горизонта;
- \(D_i(s)\) — индикатор недоступности;
- \(\mathcal{F}_t\) — доступная история наблюдений;
- \(\widehat{\mathbb{P}}\) — оценка вероятности агентом.

## Проверочный пример

Только регулярные отключения, без случайных аварий; горизонт — полные сутки.

| Нода | Недоступность | Собственная доля недоступности |
|---|---|---|
| А | 00:00–08:00 | 1/3 |
| Б | 00:00–08:00 | 1/3 |
| В | 08:00–16:00 | 1/3 |

Вес А–Б равен 1/3; веса А–В и Б–В равны нулю. Для двух взаимозаменяемых копий пара А–В лучше пары А–Б по доступности. Этот пример не доказывает сохранность при повреждениях данных.

Числовой горизонт, метод оценки вероятностей и учёт неопределённости ещё не выбраны.

# От стресс-тяжести к условной актуарной стоимости — I5.2

Наблюдённые расходы хранения и восстановления не включают ценность утраченной информации. Уничтожение копий даже уменьшает последующее хранение. Поэтому сравнение только ресурсов может ошибочно назвать потерю данных экономией.

Для ветви сначала усредняем тяжесть по внешним мирам:

$$
\overline{Z}_{a,b,s} = \frac{1}{m} \cdot \sum_{r=1}^{m} Z_{a,b,s,r}.
$$

где:

- \overline{Z}_{a,b,s} — средний объём безвозвратно потерянной принятой информации;
- a — вариант агента: Classic, G или Hybrid;
- b — профиль пропускной способности канала;
- s — ветвь стресс-сценария;
- m — число внешних миров, в I5.1 пять;
- r — номер мира;
- Z_{a,b,s,r} — потерянный объём исходной информации в этом исполнении, не объём фрагментов.

Ветви одного мира не являются независимыми повторениями. Среднее и диапазон по мирам — описательная характеристика выбранной модели, не оценка реальной частоты катастроф.

Условная стоимость заданной смеси:

$$
\widetilde{C}_{a,b}(q,W) = \sum_{s\in S} q_s \cdot \left(\overline{C}^{\mathrm{res}}_{a,b,s} + W\cdot\overline{Z}_{a,b,s}\right).
$$

где:

- \widetilde{C}_{a,b}(q,W) — условная средняя стоимость учтённых ресурсов и прямой потери информации;
- a — вариант агента;
- b — профиль канала;
- q — внешний вектор весов ветвей;
- W — внешняя цена единицы потерянной исходной информации;
- S — пять ветвей I5.1: контроль и интервалы0,5/1,5/3/7суток;
- s — конкретная ветвь;
- q_s — её явно заданный неотрицательный вес, сумма весов равна единице;
- \overline{C}^{\mathrm{res}}_{a,b,s} — средняя наблюдённая стоимость ресурсов за45суток по внешним мирам;
- \overline{Z}_{a,b,s} — средний объём потери принятой информации.

Величина условна по двум внешним входам. По умолчанию ни веса, ни W не заданы; денежная сумма неизвестна. Равные веса не подставляются автоматически. Если пользователь явно задаст веса, результат будет ожиданием по этой смеси, но не доказанной реальной вероятностью кризисов. При неизвестном W можно посчитать условный ожидаемый потерянный объём, но не полную денежную сумму.

Для двух сравниваемых вариантов граница по цене информации:

$$
W^{*} = -\frac{\overline{C}^{\mathrm{res}}_{A}(q)-\overline{C}^{\mathrm{res}}_{B}(q)}{\overline{Z}_{A}(q)-\overline{Z}_{B}(q)}.
$$

где:

- W^{*} — цена единицы информации, при которой условные суммы равны;
- A и B — две комбинации агента и профиля канала;
- q — одинаковые внешние веса сценариев для обеих комбинаций;
- \overline{C}^{\mathrm{res}}_{A}(q) и \overline{C}^{\mathrm{res}}_{B}(q) — взвешенные средние наблюдённые расходы;
- \overline{Z}_{A}(q) и \overline{Z}_{B}(q) — взвешенные средние потерянные объёмы;
- знаменатель должен отличаться от нуля.

Отрицательная точка не принадлежит области неотрицательных цен. При равной тяжести и разных расходах конечной точки нет; при совпадении обеих компонент суммы равны при любой цене. Для отдельной ветви допускается условный расчёт с единичным весом именно этой ветви; он не задаёт её реальную вероятность.

Расчёт не включает инфраструктурную премию быстрого канала, будущие расходы незавершённых работ после горизонта, правовые и репутационные последствия. Следовательно, это не полный резерв Тиле, не реальный тариф и не рекомендация выбирать агента по одной точке равенства. Денежные единицы расходов и W должны быть согласованы.

Реализация — `stress_actuarial.py`; протокол — `EXPERIMENT_I52.md`. Четыре проверки контролируют размерности на ручном примере, неизвестные входы, нормировку весов, перестановку сценариев и вырожденные точки равенства. Данные пяти миров подключаются через `report_stress_sensitivity.py` после полного парного аудита серии I5.1.

# Шаг 5. Обучение весов по наблюдениям

Дата: 7 ноября 2026 года. Статус: согласовано автором. Конкретные методы оценки и параметры ещё не выбраны.

## Наблюдения

Агент использует результаты запросов, аудитов и реестр нод. Отсутствие запланированной проверки не считается успешной проверкой. Пропуск наблюдения отличается от недоступности, подтверждённой протоколом проверки. Между проверками состояние непосредственно неизвестно.

Для первичного оценивания используем согласованные моменты проверок и контексты: время суток, день недели, известные группы риска, наблюдаемые признаки кризиса. Результат относится к наблюдаемой доступности по протоколу; перенос на непрерывное время требует модели между проверками.

## Эмпирическая оценка доступности

Для пары и выбранного контекста рассматриваем только моменты с наблюдением обеих нод.

$$
\widetilde w_{ij}=\frac{1}{m_{ij}}\sum_{r\in\mathcal{O}_{ij}}d_{ir}\cdot d_{jr},\qquad m_{ij}>0.
$$

где:
- \(\widetilde w_{ij}\) — наблюдаемая частота совместной недоступности в контексте;
- \(i,j\) — разные ноды;
- \(\mathcal{O}_{ij}\) — моменты совместного наблюдения пары в этом контексте;
- \(m_{ij}\) — число таких моментов;
- \(r\) — индекс момента проверки;
- \(d_{ir},d_{jr}\) — наблюдаемые индикаторы недоступности по протоколу.

Неравномерный или зависящий от состояния выбор проверок может смещать частоту. Для базового опыта нужны регулярные проверки либо явный учёт механизма наблюдения. Частые проверки одной аварии не являются независимыми примерами.

## Кредибилити

$$
\widehat w_{ij}=z_{ij}\cdot\widetilde w_{ij}+(1-z_{ij})\cdot w_{ij}^{0},
\qquad z_{ij}=\frac{e_{ij}}{e_{ij}+K}.
$$

где:
- \(\widehat w_{ij}\) — предварительная сглаженная оценка для контекста;
- \(\widetilde w_{ij}\) — эмпирическая оценка пары;
- \(w_{ij}^{0}\) — базовая оценка из общей модели с учётом известных групп и собственных рисков;
- \(z_{ij}\) — степень доверия собственной истории;
- \(e_{ij}\ge0\) — эффективный объём опыта с учётом временной зависимости;
- \(K>0\) — параметр сглаживания, подлежащий оценке на прошлых данных;
- \(i,j\) — ноды.

При отсутствии опыта используем базовую оценку без вычисления эмпирической частоты. Это проект принципа кредибилити, а не утверждение, что выбранная формула является уже откалиброванной моделью Бюльмана–Штрауба.

Предварительные парные оценки нельзя без проверки объявлять согласованным совместным распределением. Итоговые веса и риск объекта должны быть получены из общей модели сценариев либо согласованы с ней. Расписания, факторы площадки, провайдера, ПО и индивидуальные события формируют совместные сценарии; истинные скрытые признаки мира агенту не передаются.

Горизонтный вес шага 2 получается усреднением предсказаний контекстной модели по будущему окну. Историческая частота сама по себе не является прогнозом на произвольный горизонт.

## Потери данных

Слой потери обучается отдельно. Используются подтверждённые потери, история успешных аудитов и экспозиция хранения. Время скрытой потери обычно известно лишь между последним успешным и первым неуспешным аудитом. Молчание ноды не доказывает уничтожение чанка; решение начать восстановление не является меткой истинной потери.

Предлагается оценивать индивидуальные интенсивности и общие события по наблюдаемым данным, затем моделировать совместные пути и получать собственные и парные вероятности из этих путей. Конкретная модель цензурирования, общих причин и скрытого ухода ещё не выбрана. Нельзя напрямую переносить частоты недоступности в вероятности безвозвратной потери.

## Неопределённость

$$
w_{ij}^{+}(t,H)=Q_{1-\delta}\!\left(W_{ij}(t,H)\mid\mathcal{F}_t\right).
$$

где:
- \(w_{ij}^{+}(t,H)\) — верхняя оценка риска для осторожного ранжирования;
- \(Q_{1-\delta}\) — квантиль уровня \(1-\delta\);
- \(0<\delta<1\) — выбранный уровень хвоста;
- \(W_{ij}(t,H)\) — неопределённое значение веса в ансамбле допустимых моделей;
- \(i,j,t,H\) — пара нод, момент решения и горизонт;
- \(\mathcal{F}_t\) — доступные наблюдения.

Распределение неопределённости ещё нужно построить и проверить, например через повторную подгонку по временным блокам. Формула — предложение, не готовый доверительный интервал. Верхние оценки отдельных рёбер не гарантируют ограничение риска объекта целиком. Для него требуется отдельная проверка по согласованным совместным сценариям с учётом неопределённости.

## Обновление и проверка

Наблюдения поступают последовательно; параметры обновляются по расписанию или при заметном изменении среды. Давность опыта и смена ПО либо площадки учитываются моделью, а не обнулением риска. Частота обновления, окно истории и объём старого опыта ещё не выбраны.

Обучение выполняется только на прошлом. Будущие отрезки служат для проверки калибровки собственных и совместных рисков, доступности объектов и потерь. Истина симулятора используется оценщиком качества отдельно от агента. Сравниваются базовая модель, модель без сглаживания и обучаемая модель с групповыми зависимостями. При редких потерях отсутствие потерь в проверке не доказывает точность малой вероятности.

Следующий шаг после согласования: небольшие проверочные примеры. Реализация и выбор числовых параметров не начаты.

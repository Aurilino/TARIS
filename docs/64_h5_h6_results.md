## Основные выводы

В основной серии защита снизила средние потери с 54.95 до 47.00 объекта из 90 (14.5%), а средний ремонтный трафик вырос на 30.1%. Парный интервал потерь не включает ноль; в дополнительных сериях интервалы шире и включают ноль. Преимущество по полной стоимости не установлено.

При слабых публичных связях одного лимита найденной группы недостаточно: реальный владелец может быть разбит на несколько кластеров. Защита сильнее помогает при более заметных утечках, но увеличивает обслуживание. В основной серии абляции без лимита новичков дают тот же результат, а без мягкого штрафа выигрыш по потерям исчезает. Это относится к данному протоколу с начальным наблюдением сети и не доказывает бесполезности лимита новичков при других регистрациях.

Нулевое раскрытие в защищённой выборке не подтверждает крайне малую вероятность раскрытия: данных мало. H5 в полном объёме не подтверждена. H6 показывает зависимость восстановления владельца от силы заданных синтетических сигналов, а не внешнюю валидацию на реальных атаках.

## Почему сильный сигнал не всегда предотвращает потери

Исследовательская диагностика зерна 6 при утечке 0,6: потеряно 55 объектов, в момент атаки — 54. На сутках 30 общий граф защиты объединял 58.3% пар Сибиллы, на сутках 60 — 82.7%, на сутках 90 — 100%, но атака произошла на сутках 84.
В первом объекте было 4 фрагмента у истинного оператора Сибиллы, а максимальная группа по известному тогда графу содержала 3. Лимит три соблюдался для найденных групп, но один реальный владелец оказался разделён между ними. При последующем объединении групп политика не пересобирает прежние наборы автоматически. Это ограничение текущего механизма, а не основание объявить предсказание успешным по более позднему графу.

Диагностика выбрана после просмотра исходов и не использовалась для подбора параметров. Воспроизведение: `python scripts/diagnose_protection.py --seed 6 --p-leak 0.6`.

## Границы выводов

Раскрытие оценивается при явно заданной утечке ключа доступа на сутках 30. Без неё сбор фрагментов не означает чтение открытого текста. Нулевые раскрытия сами по себе не доказывают малый целевой риск.
Для полной защиты в серии main: миров с раскрытием 0 из 20; односторонняя верхняя 95%-я граница вероятности мира с хотя бы одним раскрытием — 13.91%. Это не граница вероятности раскрытия одного объекта.
Для полной защиты в серии s4: миров с раскрытием 0 из 10; односторонняя верхняя 95%-я граница вероятности мира с хотя бы одним раскрытием — 25.89%. Это не граница вероятности раскрытия одного объекта.
Для полной защиты в серии small: миров с раскрытием 0 из 10; односторонняя верхняя 95%-я граница вероятности мира с хотя бы одним раскрытием — 25.89%. Это не граница вероятности раскрытия одного объекта.

H5 целиком не проверена: нет денежного тарифа в этом сравнении, вероятностного допуска по раскрытию и адаптивного противника. Ограничение текущего набора не ограничивает автоматически исторические копии коалиции. При нехватке допустимых узлов защита отказывает в операции; начальные отказы включены в суммарные потери.

H6 здесь проверяет синтетический механизм известных сигналов. Парная полнота близка к частоте внедрённых финансовых рёбер по построению, а кластеризация может объединять лишь часть владельца. Для внешней валидации нужны реальные или независимо заданные загрязнённые сигналы.

Все интервалы относятся к мирам-зёрнам; объекты внутри мира не объявляются независимыми наблюдениями. Абляции и чувствительность исследовательские. Результаты не переносятся автоматически на длинный горизонт, S7 и несогласованный мир.

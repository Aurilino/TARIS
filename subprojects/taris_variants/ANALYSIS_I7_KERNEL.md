# I7 — математический минимум доменного запаса

13ноября2026. Созданы `domain_reserve.py`, `test_domain_reserve.py`, `report_domain_reserve.py`. Основная модель и старые серии не менялись; новый решатель не подключён к агентам.

Задача: разные номера, один номер на узел, фиксированный бюджет bдоменных отказов, порог kиограничения числа допустимых узлов по ДЦ. Минимум без ёмкостей выведен аналитически; ограниченная задача решается перебором числа номеров и раскладок. При превышении вычислительного бюджета возвращается неизвестная разрешимость.

Шесть тестов пройдены, включая независимый перебор подмножеств узлов для всех малых конфигураций. Полная проверка подпроекта180тестов OK; ранее56тестов неизменённого прототипа. Десять задач с независимой проверкой сохранены в `domain_reserve_i7/`.

Это условный минимум числа чанков одного объекта при фиксированном снимке кандидатов, не глобальный минимум всей сети/даты, не оценка реальной вероятности катастрофы и не полный актуарный резерв. Дополнительные копии одного номера не входят в упрощённую новую раскладку. Для текущих физических данных остаются неизвестная целостность, давность аудита, принятие/подтверждение записей и незавершённая передача.

# I4.3. Передача с сохранением префикса и безопасное освобождение буфера

Протокол до испытания. Дата: 10 ноября 2026 года.

Новая версия `ResumableLedger` не изменяет I4.2. Объект читается последовательно 16 полосами. Одна полоса декодируется из k разных источников целиком; неудачная попытка теряет только текущую полосу. Проверенные предыдущие полосы сохраняются в памяти. Источники разрешено выбирать заново перед каждой полосой. Частичных полос нет.

После получения всего объекта создаётся полный буфер. Каждый новый чанк также записывается последовательно 16 блоками: подтверждённый префикс переживает обычный простой получателя. Уничтожение диска или уход сбрасывают его незавершённый префикс; попытка в пути проверяет поколение диска. Полный чанк появляется только после последнего блока. После неудачи или отсутствия источников/получателя повторная попытка — через один час; будущее время окончания простоя не используется.

Недоступного получателя ожидают до T_rep с момента первого неуспешного подключения. После этого задание может быть безопасно отменено без записи только через подтверждение целого дискового кода; если код не подтверждён, буфер продолжает удерживаться. Отмена не считается восстановлением требуемого резерва.

Все незавершённые префиксы последовательные и не содержат последнюю полосу. Поэтому они сами не устраняют дефицит полного дискового кода для всего объекта: неполученный суффикс всё ещё требует k полных чанков. Это позволяет сохранить точное условие восстановимости целого объекта в данной модели: k разных целых дисковых номеров либо полный буфер. Нельзя переносить это упрощение на произвольный порядок блоков или частичные повреждения чанков.

После попытки записи последний полный буфер не удаляется автоматически. Освобождение допускается только после оплаченной проверки k разных полных копий в активной карте. Подготовка — 0,05 часа, объём проверки — 0,01 полного объекта; тот же общий канал. Неудачная проверка сохраняет буфер. Негативный результат целостности при доступном узле отражается в сетевом журнале. Проверка не использует будущие события.

Пока буфер удерживается, сервер остаётся занят данным объектом. Агент может передать этому же заданию новые получатели для признанных недостающих номеров через обычные запросы ремонта. Остальные задания ждут. Нет скрытого сброса по TTL; отказ самого буфера остаётся отдельным событием. Это приоритет сохранения информации с возможной блокировкой очереди при нехватке места или доступных получателей.

Центральная память ограничена одним объектом: декодированный префикс превращается в полный буфер без удвоения памяти. Незавершённая запись использует временную область получателя до размера одного чанка; её префикс не считается полной копией и отдельно учитывается в объёмо-сутках. При завершении/отмене задания временная область освобождается по абстрактному протоколу очистки; задержка такой очистки не моделируется. Слоты полных копий резервируются, как в I4.2.

Предварительно заданы 16 полос, повтор через час; те же скорости 2 и 0,02 объёма объекта в час, очередь 8, буфер 1. S2, 45 суток, 24 начальные ноды, k=2, n=4; Classic, G, Hybrid. Зёрна 15–17 — парное сравнение с неизменёнными журналами I4.2; 18–20 — новые проверочные миры. Всего 36 исполнений на шести мирах. Повторное использование 15–17 не считается независимым подтверждением.

Проверяются сохранение прогресса после прерывания, смена источников между полосами, сброс незавершённой записи при уничтожении, отказ памяти, удержание последнего буфера и добавление новых номеров, стоимость закрывающей проверки, общий канал, память, очередь и хвост горизонта. Аудит отдельно пересчитывает полезные префиксы, исходы блоков, появление полных копий, безопасное освобождение буфера и потери. Параметры после просмотра проверочных миров не подбираются.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
.venv\Scripts\python.exe -B -W error subprojects/taris_variants/run_resumable.py
.venv\Scripts\python.exe -B -W error subprojects/taris_variants/audit_resumable.py
.venv\Scripts\python.exe -B -W error subprojects/taris_variants/report_resumable.py
```

По умолчанию серия записывается в `series_i43/`. Несовместимый кэш не переиспользуется; для изменённой версии требуется новая папка через `--output-dir`. Аудит другой папки — `--directory`. Парный отчёт сопоставляет канонические журналы I4.2/I4.3 и не запускает новые миры.

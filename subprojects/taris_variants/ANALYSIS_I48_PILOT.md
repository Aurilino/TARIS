# I4.8 — инженерный пилот, зерно 30

Шесть исполнений S2 (45 суток, 24 узла, k=2, n=4) сохранены в `series_i48_pilot/`. Это один внешний мир, не шесть независимых миров. Каждое исполнение повторено исходным TargetedProofLedger без наблюдения: задания, сегменты, блоки, буферы, планировщик, выбор proof, первичные записи и итоговые метрики совпали. Мир и входные таблицы одинаковы для вариантов и каналов.

Физический/транспортный аудит выполнен для всех шести исполнений прежними независимыми функциями I4.4c. `audit_observed.py` отдельно пересчитал последующее обслуживание по фазам и проверил временную границу, белый список и цензуру. Он не вызывает функцию построения меток. Полная проверка подпроекта: 136 тестов OK; ранее пройдены 56 тестов неизменённого прототипа.

Суточные снимки сделаны перед решениями. На быстром канале все задания этого мира завершались между такими снимками: общий бюджет ненулевой (33,383; 30,250; 31,781), но обучающих строк о текущих заданиях нет. Это ограничивает калибровку по текущей очереди; нельзя интерпретировать пустые снимки как отсутствие работ или затрат за сутки. Новые заявки, создаваемые после решения, также ещё не входят в снимок.

На медленном канале хвост — по восемь заданий в каждом исполнении; бюджеты 9,619; 11,873; 8,571. В части цензурированных строк уже есть ненулевые будущие до горизонта расходы. Их полная будущая цена и время завершения сохранены как null. Повторные строки одного задания зависимы, их нельзя считать независимыми событиями.

Пилот принят в инженерном смысле для задачи оценки очереди на суточной границе. Контракт и параметры не меняются перед обучением. Для оценки коротких заданий потребуется отдельная событийная выборка; текущая серия этого не обещает. Следующие миры 31–33 — обучение, 34–36 остаются отложенными. Обучение только по завершённым заданиям может дать смещение из-за цензуры; перед выбором метода требуется посмотреть структуру обучающего набора, не открывая проверочные исходы.

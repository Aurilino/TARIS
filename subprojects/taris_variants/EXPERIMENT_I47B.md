# I4.7b — сверка с продолжением

Сначала проверяем I4.7a без изменения исполнителя: три границы частичного чтения/записи, две ветви с одинаковым наблюдаемым прошлым, одна с будущим прерыванием источника. Истина используется только внешним проверяющим для построения сценария и измерения результата, не расчётом агента.

I4.7a условно отбрасывает неподтверждённую часть блока, тогда как обычное продолжение сохраняет уже обслуженную часть текущей фазы. При отсутствии новых событий разность между условным объёмом и фактической будущей передачей должна равняться уже обслуженному объёму текущего неподтверждённого блока. Это не ошибка расчёта. При новом прерывании появляются оплаченная неуспешная попытка и повтор.

Проверить: равенство снимков до будущего события, точное равенство объёмов с поправкой текущей фазы без новых отказов, положительное дополнительное обслуживание и неуспешный ответ при прерывании, фактическое завершение и отсутствие цензуры. Сохранить сегменты, снимки, расчёт и численные остатки.

Самостоятельный proof получает известный плановый объём только после планирования фазы `proof`. Для ещё не подготовленной проверки объём остаётся неизвестным. Нельзя раскрывать скрытый инвентарь диска ради заполнения этой величины. Полная оценка очереди отложена до отдельного наблюдаемого протокола инвентаризации.

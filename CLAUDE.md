# TARIS — магистерская диссертация (МГИМО)

Тема: «Актуарные методы тарификации узлов хранения в работе ИИ-агента управления данными блокчейна» (TARIS — Tariff-based Allocation of Replicas In Storage). Автор — Андрюничев В.В., магистратура «Бизнес-информатика», профиль «Искусственный интеллект»; по профессии актуарий.

Главная цель: построить модель работающего блокчейна (слой хранения данных), встроить в неё своего агента, моделировать отключения и кризисы и показать, как агент с ними справляется и как он учится предвидеть кризисы. Принцип: что можно предсказать (кризисы с предвестниками) — агент предсказывает и действует заранее; что нельзя (внезапные) — страхуется диверсификацией размещения и резервом информации.

## Как работать

- Язык общения и документов — русский.
- Работаем по шагам, не спешим: сначала план или список шагов, затем выполнение одного шага, затем ждём подтверждения пользователя. Не переходить к следующему шагу без его «ок».
- Формулы: каждая формула на отдельных строках между `$$`, с явными операторами (`=`, `-`, `+`, `\cdot`, `\frac`); после каждой формулы — блок «где:» с расшифровкой всех переменных.
- Ссылки на литературу — сквозная нумерация (шаг 1: [1]–[25], шаг 2: [26]–[56], шаг 3: [57]–[63]).
- Источник истины для всех расчётов — Python-симулятор. Визуализация (вариант B) только проигрывает журналы прогонов и принимает вмешательства в виде файлов сценариев.

## Состояние кода

Готово (шаг 3): `config`, `rng`, `world` (узлы, истинный риск, простои, шоки/бури, уход, тихие потери), `data`, `chain` (микропрерывания, пинги, аудиты, `reset()`/`step()`), `ledger` (сквозной прогон, потери, восстановление, метрики), `policy` (равномерное размещение и оракул). Проверки: `scripts/check_world.py`, `check_chain.py`, `check_ledger.py`. Графики: `scripts/plot_*.py`. Демонстрация среды: `viewer/env_demo_template.html` + `scripts/build_demo.py`.

Не сделано: предвестники кризисов и библиотека кризисов в мире; модуль `reserve` (уравнение Тиле, минимальный резерв, IBNR); `adversary`; `validate`; агент TARIS (шаг 5).

Принципы кода: единица времени — сутки (эпоха), длительности простоев — в часах; случайность мира — через `rng.stream(seed, ...)` и не зависит от решений политики (общие случайные числа); мир генерируется заранее; согласованный и несогласованный режимы мира (`world_mode`).

## Окружение

Windows 11. Python 3.12 в виртуальном окружении `.venv`. Переменная `PYTHONUTF8=1` включена (UTF-8 по умолчанию для файлов и вывода). Claude Code выполняет команды через Git Bash, если установлен Git for Windows, иначе через PowerShell.

## Команды

PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python scripts\check_world.py
python scripts\check_chain.py
python scripts\check_ledger.py
python scripts\run_baselines.py runs uniform15
python -m http.server 8000    # просмотр страниц из viewer\ в браузере: http://localhost:8000
```

Git Bash:

```bash
source .venv/Scripts/activate
python scripts/check_world.py
```
